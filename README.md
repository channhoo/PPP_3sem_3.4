## Описание проекта

«Астероиды» — двумерная космическая аркада в пиксельном стиле.
Игрок управляет кораблём, уклоняется от астероидов и уничтожает
их ракетами, чтобы набрать очки.

## Функциональные возможности

- Заставка с запуском игры по щелчку мыши.
- Вращение корабля, ускорение, постепенное торможение и стрельба.
- Переход объектов через противоположный край экрана.
- Случайное появление астероидов и покадровая анимация взрывов.
- Счётчик очков и три запасных возрождения.
- Капсула, из которой после попадания выпадает бонусная жизнь.
  Чтобы получить её, нужно подобрать бонус кораблём.

## Требования к системе

- Python 3.12
- pygame 2.6.1

## Установка и запуск

Склонируйте репозиторий и откройте его папку в PowerShell.
В команде ниже указан адрес репозитория проекта.

```powershell
git clone https://github.com/channhoo/PPP_3sem_3.4.git
cd PPP_3sem_3.4
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Структура проекта

- `main.py` — окно, заставка, управление, игровой цикл, столкновения и счёт.
- `entities.py` — корабль, ракеты, астероиды, взрывы, капсула и бонус.
- `settings.py` — параметры движения, появления объектов и анимации.
- `assets/` — пиксельные спрайты и лист из пяти кадров взрыва.
- `requirements.txt` — версия pygame.

## Пример игры

Щёлкните по заставке, чтобы начать партию. Стрелки `←` и `→`
поворачивают корабль, `↑` включает двигатель, `Пробел` выпускает
ракету, а `Esc` закрывает окно.

За каждый сбитый астероид начисляется одно очко. Попадите ракетой
в бирюзовую капсулу, затем подберите янтарный значок кораблём в течение
семи секунд, чтобы получить дополнительное возрождение.

В начале партии доступны три запасных возрождения. Если корабль
сталкивается с астероидом при нулевом запасе, игра возвращается
на заставку и показывает итоговый счёт.
