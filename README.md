## Описание проекта

«Астероиды» — двумерная космическая аркада в пиксельном стиле.
Игрок управляет кораблём, уклоняется от астероидов и уничтожает
их ракетами, чтобы набрать очки.

## Планируемый функционал

- Заставка с запуском игры по щелчку мыши.
- Вращение корабля, ускорение, постепенное торможение и стрельба.
- Переход объектов через противоположный край экрана.
- Случайное появление астероидов и покадровая анимация взрывов.
- Счётчик очков и три запасных возрождения.
- Капсула, из которой после попадания выпадает бонусная жизнь.
  Чтобы получить её, нужно подобрать бонус кораблём.

## Технологии

Python 3.12 и pygame 2.6.1.
